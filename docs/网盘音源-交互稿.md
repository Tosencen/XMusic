# 网盘音源 · 详细交互稿

> 2026-10-29 · XMusic v1.1.3+
> 范围：阿里云盘 + 夸克网盘（百度后续评估）

---

## 一、总体架构

```
设置页 ──右上角[云盘图标]──→ 网盘音源管理弹窗（登录/登出/设主音源）
                                    │
首页 ──「网盘音乐」卡片（只显示主音源）──→ 网盘目录/资源详情（复用歌单详情 UI）
                                    │
                          播放：HTTP 直链 → OkHttp 边播边存（现有管线）
```

**核心概念**
- **多登录共存**：阿里、夸克可同时登录，凭据各自独立（EncryptedSharedPreferences）
- **主音源**：唯一，决定首页卡片显示谁的资源；单选标记
- **未登录任何网盘**：首页卡片**隐藏**（不占位）；设置页入口仍在

## 三、网盘音源管理弹窗（核心）

### 形态
- ModalBottomSheet（从下滑入，scrim 淡入——与播放弹窗同语言）
- 圆角 28dp 顶部，maxHeight 70% 屏高

### 布局
```
┌─────────────────────────────────────┐
│  网盘音源管理                      ×  │  ← 标题栏（关闭按钮）
├─────────────────────────────────────┤
│  ┌───────────────────────────────┐  │
│  │ [图标] 阿里云盘                │  │
│  │        已登录 · 张*三          │  │  ← 已登录态
│  │        [设为主音源 ✓] [退出登录]│  │
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │ [图标] 夸克网盘                │  │
│  │        未登录                  │  │  ← 未登录态
│  │        [登录]                  │  │
│  └───────────────────────────────┘  │
│                                     │
│  当前主音源：阿里云盘                 │  ← 底部摘要行（实时同步）
└─────────────────────────────────────┘
```

### 组件细节

**源卡片（每网盘一行）**
- 图标：官方色系圆形图标（阿里橙、夸克蓝）+ 24dp
- 状态文案：`已登录 · 昵称` / `未登录`
- 按钮组：
  - **已登录**：`设为主音源`（已是主音源则显示 ✓标记 + disabled 态）+ `退出登录`（文字按钮，error 色）
  - **未登录**：`登录`（FilledTonalButton）
- 选中主音源的卡片：主色描边 1dp + 底部浅主色 tint

**底部摘要行**
- 文案：`当前主音源：{源名}`；全未登录时显示 `未设置主音源`

### 交互规则
| 操作 | 行为 |
|------|------|
| 点「登录」 | 跳转 OAuth（Custom Tab/内置 WebView）→ 成功回来卡片变已登录态，**自动设为主音源**（若当前无主音源） |
| 点「设为主音源」 | 主音源切换，标记即时移动，摘要行更新，**首页卡片内容随之刷新** |
| 点「退出登录」 | 二次确认（`退出后需重新登录才能播放网盘音乐`）→ 清凭据；若退出的是主音源 → 主音源自动切到另一已登录源，无则置空（首页卡片隐藏） |
| 点 × / scrim / 返回键 | 关闭弹窗 |
| 登录失败 | 卡片内联错误（`登录失败，重试`），不留 toast 孤儿 |

## 四、首页 · 网盘音乐卡片

### 显示条件
- ≥1 个网盘已登录 → 显示
- 全未登录 → **隐藏**（整卡不占位）

### 布局
```
┌──────────────────────────────────────────┐
│  夸克云盘音乐                    ⇄ [图标] │  ← 标题=主音源名；⇄=快捷切换
│  最近添加 · 128 首                        │  ← 副标题（可换摘要）
│  [封面1] [封面2] [封面3] [封面4] …        │  ← 横向封面带（最近/随机）
└──────────────────────────────────────────┘
```

- 标题：`{主音源名}音乐`（明确来源，不叫笼统"网盘音乐"）
- 右上 `⇄` 图标：点击弹出**快捷源切换小菜单**（仅列已登录源，点选即切主音源）——高频操作就近
- 卡片点击：进入网盘资源详情（目录/歌单式，复用 SongList 详情 UI）
- 封面带：主音源最近添加的 4-5 张封面（点单张进对应专辑/目录）

### 状态
| 状态 | 表现 |
|------|------|
| 扫描中 | 封面带骨架屏 shimmer |
| 切换主音源 | 内容 300ms 交叉淡入刷新 |
| 源离线 | 卡片置灰 + 文案 `源不可用，点击重试` |

## 五、网盘资源详情页

- **完全复用现有歌单详情 UI**（SongList 那套：列表/批量操作/播放全部）
- 顶部面包屑：`夸克云盘 / Music / 2026`（多级目录可下钻/返回）
- 行为与本地歌单一致：点歌即播（HTTP 直链 → OkHttp 缓存管线）、长按菜单（下一首播放等）
- **不支持**删除/移动网盘文件（只读源保护——同 primuse 原则）

## 六、与现有音源共存（资料库融合）

**原则**：网盘 = 又一个"源"，不另起炉灶——顺着现有融合点接进去。

| 融合点 | 处理方式 |
|--------|---------|
| 搜索 | 网盘目录缓存建索引，与本地/插件音源**并行搜索** |
| 播放队列 | 零改动（PlayableEntry 天然混合本地+在线+网盘） |
| 收藏/歌单 | 零改动（key=sourceId/rawId，网盘曲目自带 id） |
| 首页 | 网盘卡片与本地卡片/在线推荐并列（见第四节） |

### 6.1 搜索结果 · 分组折叠（已拍板）
- 结果按来源分组：`本地 · n` / `{主音源} · n` / `在线 · n`
- **本地 + 网盘组置顶**（"你的歌"优先），在线组在后
- 每组默认取 Top 5，`展开全部` 看完整组
- 组内按相关度排序（现有多源并行搜索逻辑不变）

### 6.2 多源重复 · 不去重（已拍板）
- 同一首歌网盘/在线都有 → **两源并存**，不合并
- 来源以 **chip 徽标**区分（见 6.3），用户自选听哪个
- 收藏按"当前播放的源"记录，不会串源

### 6.3 来源标识 chip
- 所有歌曲条目（搜索结果/列表/播放页）歌名旁加来源小 chip：`本地` / `夸克` / `阿里` / `网易` 等
- chip 配色跟随来源（本地灰、网盘主色、在线浅蓝），3-5dp 圆角小标签
- 播放详情页歌名下方同款 chip

## 七、状态流转

```
[未登录] --点登录--> [OAuth 跳转] --成功--> [已登录] --（若无主音源）--> 自动设为主音源
                                    --失败--> [未登录+内联错误]
[已登录] --退出--> [二次确认] --确认--> [未登录]；主音源被退 → 迁移到另一源/置空
[已登录A,已登录B] --设 B 为主音源--> 首页卡片内容切到 B（平滑刷新）
```

**凭据生命周期**：登录成功 → refresh_token 入 EncryptedSharedPreferences → 播放时静默刷 token → 过期重登。

## 八、边界情况

| 场景 | 处理 |
|------|------|
| 登录中途返回/取消 | 回到弹窗原状态，无残留 |
| 网络异常 | 卡片内联重试，不弹全局错误 |
| 直链过期（阿里 15 分钟） | 播放器报错 → 自动重取直链续播（复用 recoverAndPlay） |
| 两源同名文件 | 不冲突（各自独立资料库域） |
| 卸载重装 | 凭据随 EncryptedSharedPreferences 清空，需重登 |
| 主音源切换后正在播放 | 播放不中断（播放队列独立于浏览源） |

## 九、技术落点（与现有架构的接口）

| 模块 | 复用/新增 |
|------|----------|
| 取直链 + 播放 | 复用 staged 播放 + OkHttp 边播边存（今日新增） |
| 曲目模型 | 复用 PlayableEntry（新增 sourceType=ALIYUN/QUARK） |
| 资料库 | 新增网盘资源缓存表（目录快照，断点续扫） |
| 凭据 | EncryptedSharedPreferences（已有） |
| 首页卡片 | 新增 CloudMusicCard（参照 LocalMusicCard） |
| 管理弹窗 | 新增 CloudSourceSheet（ModalBottomSheet） |
| OAuth | 阿里：官方 open API；夸克：Web 接口封装（独立 module，隔离风险） |
